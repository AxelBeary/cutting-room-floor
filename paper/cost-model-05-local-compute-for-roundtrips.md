# 四、派生纪律③：主动用墙钟与本地算力去换往返次数

这一节是整篇里我们自己用得最狠、但在公开材料里最难找到逐字同类的说法。先把它立成一句可执行的话：

> **本机算力不紧张，贵的只有 AI 来回。所以允许、并且鼓励主动拿墙钟时间与本地算力去换往返次数。**

## 4.1 为什么这笔交换是划算的

回到那个式子。本地算力和墙钟时间的价格，在这个环境里**接近零且与 N 无关**：你的机器在代理等你回复的时候本来就是空转的；跑一次全量测试多花四十秒，那四十秒里模型侧什么都没干。而往返次数的价格是二次的。

也就是说，这两样东西的边际成本差着量级：**你拿去换的东西几乎免费，你换回来的东西按二次方计价。** 只要交换比不是太离谱，就该换。

于是下面这些"看起来很奢侈"的操作，在我们这儿都是明确许可的：

- **一次调用跑完全部闸门**，而不是跑一道、看一眼、再跑下一道。哪怕总共要跑十分钟，也比十次往返便宜——那十分钟机器本来就在等。
- **内置双路互证。** 同一个结论用两条独立路径算一遍再对齐（比如一份靠静态解析抠数字、一份靠运行时抓状态）。多数人的直觉是"这不是翻倍花 token 吗"——不是。两条路径都在本地跑，模型只读一次**对齐之后的结论**。覆盖面翻倍，往返一趟没多。
- **明细全量落盘。** 一次验收的逐道原始输出可能是十 MB 量级（我们某批实测就是十几 MB，某时点数字，发布前复算）。让它全落盘，一个字都不进上下文，只留文件指针。反正磁盘不要钱。
- **同一件事多跑一遍复算。** 在本地这一趟里重算一遍、和上一批留档比一遍，几乎总是划算的。
- **跑得慢但更硬的检查值得跑。** 起一个真实例、真打包、真编译这种动辄几十秒的机械检查，只要它在同一次调用里跑完，就不要为了省时间换成"轻量近似检查"。

最后一项要单独强调，因为它最常被违反：很多人会为了"让代理快点出结果"，把重检查换成轻检查，然后靠多轮追问去补判断。这是拿**二次方计价的往返**去换**接近免费的本地时间**，方向完全反了。

## 4.2 一个反直觉结论：多跑一遍可能是免费的，多问一句一定不是

在 AI 侧，成本按"发生了多少趟"结算，不按"你机器算了多久"结算。所以：

- **一次调用之内多算三遍**：模型侧只有一趟，成本 ≈ 一份输出体积。
- **少算一遍、多问一次**：模型侧两趟，而且第二趟要重传第一趟的全部历史。

这两件事在"我少做了多少工作"的直觉下看起来差不多，在账单上差着一个数量级（趟数越大差得越多，因为它跟着二次方走）。我们内部现在有句话专门用来堵这个坑：**能在这一趟里算完的，就别留到下一趟问。**

## 4.3 别和 Batch / 低优先级折扣混为一谈

这是一处非常容易的混淆，值得单独拆开。

各家提供的批处理 / 异步 / 弹性计价档位（公开报价通常是五折、代价是接受最长可达一天的完成窗口）做的也是"用时间换钱"这笔交易，但换的不是同一个东西：

| | 你交出什么 | 你换回什么 | 作用在式子哪一项 |
| --- | --- | --- | --- |
| Batch / 弹性档位 | 墙钟（异步、延迟容忍） | **单价**打折 | 所有项的公共系数 |
| 本节的纪律 | 本地算力 + 墙钟 | **往返次数**下降 | 二次方项本身 |

两者方向不同、量纲不同、**可以叠加**，而且叠加时才看得清主次：Batch 给你的是一次方以下的常数折扣，压趟数给你的随 N 增长的超线性收益。N 小的时候前者更明显，N 大的时候后者碾压前者——而 N 大恰恰就是"多代理协作"这个名字的本意。

同理，"双路互证值不值那点 token 溢价"这类常见讨论，问的是**同一趟内多花上下文换可靠性**；我们这儿问的是**多花本地时间换更少趟数**。两个问题都合理，但别拿一个的答案去回答另一个。

## 4.4 什么时候这条不成立

它依赖三个前提，前提破了就该反过来算：

1. **本地算力真的不紧张。** 如果闸门跑在共享 CI 上、有并发配额、或者占着别人的 GPU，那本地时间就不是免费的，"换"要重新核算。
2. **墙钟没有硬 SLA。** 线上故障处置、有人在现场等的交互式场景，延迟本身很贵，这时候该拿往返换时间（哪怕多发几趟，也要更快拿到部分结果）。
3. **多跑没有副作用。** 重复跑如果会污染外部状态、触发不可逆动作、或者产生需要清理的垃圾，那"多跑一遍复算"就不再免费——要先把这些检查改造成可重入的。

我们的环境三条都成立，所以这条纪律对我们成立。这是个**条件结论**，不是普适结论。

## 4.5 一句判据

把这一节压缩成一句可以贴在屏幕边上的话：

> **任何能在本地算出确定答案的事，都不值得占一次往返；任何能在同一趟里做完的检查，都不要留到下一趟。**

至于"检查该不该做"——那是下一节的事，而且答案不受成本决定。
