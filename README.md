# Cutting Room Floor（剪辑室地板）

电影剪辑里有个说法：正片没要的那些镜头，剪下来堆在剪辑室的地板上。它们没进最终成片，但每一段都舍不得扔——有时候还是整部片子里最好的几分钟。

这个仓库就是那块地板。

这里收录从 Jigsaw Puzzles 等项目的实际开发过程里沉淀出来的对外发表物：论文、方法论、技术博客、踩坑录，以及一路上积累下来还能给别人看的材料、图表和数据。游戏仓里的代码是正片，这里是从中被剪下来、单独看才有意思的部分。

一句话规则：**只有过完脱敏闸的东西才有资格从车间区挪进上面三个打勾的目录。**

目录不是一次定死的：将来还会有别的类型的东西进来，新东西一律先进 `wip/`，确认该归哪类再登记入库。

## 发布与授权

仓库目前为 **GitHub 私有仓**，仅作异地备份与预览，尚未对外发布。异地备份远端已经用户放行建立（2026-09-19，每轮收口提交后推送）；**转公开、加公开远端与对外发布仍需用户逐次明确放行**（见仓内红线）。稿件材料来自单一项目的实际实践，**并由 AI 协助整理**（检索、比对、改写与格式均由代理参与，结论与取舍由人定）。

授权待定：当前未附开源许可证（保留所有权利）。计划于对外发布时采用**文字部分 CC BY-NC-SA 4.0**（署名 + 非商业 + 相同方式共享）、**代码片段单独 MIT**。届时会同时复核两件：引用段落（安全标准条款、他人论文结论）不在可授权范围内，以及 CC0 类不可撤回的公开领域声明会失去投稿与约稿资格——所以不走 CC0。
