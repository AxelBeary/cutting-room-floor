# Cutting Room Floor（剪辑室地板）

电影剪辑里有个说法：正片没要的那些镜头，剪下来堆在剪辑室的地板上。它们没进最终成片，但每一段都舍不得扔——有时候还是整部片子里最好的几分钟。

这个仓库就是那块地板。

这里收录从 Jigsaw Puzzles 等项目的实际开发过程里沉淀出来的对外发表物：论文、方法论、技术博客、踩坑录，以及一路上积累下来还能给别人看的材料、图表和数据。游戏仓里的代码是正片，这里是从中被剪下来、单独看才有意思的部分。

一句话规则：**只有过完脱敏闸的东西才有资格从车间区挪进上面三个打勾的目录。**

目录不是一次定死的：将来还会有别的类型的东西进来，新东西一律先进 `wip/`，确认该归哪类再登记入库。
